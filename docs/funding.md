# Funding DevBridge

DevBridge uses **GitHub Sponsors only** as its repository funding path. No Patreon, Ko-fi, Buy Me a Coffee, Open Collective, or other public donation account is configured.

The repository contains:

```yaml
# .github/FUNDING.yml
github: iteathen
```

Once the `iteathen` GitHub Sponsors profile is active, GitHub can surface the repository Sponsor button and direct support to that existing GitHub identity.

## What sponsorship pays for

DevBridge sponsorship is intended to offset the direct cost of developing and maintaining the project, especially:

- AI model/API tokens used for implementation, review, testing, and research;
- GitHub account/tooling costs associated with project development;
- local/hosted compute and infrastructure used to build and test DevBridge;
- other direct project maintenance expenses.

Keep the funding description concrete. Sponsors are funding continued open-source development, not buying machine authority, task priority, security exceptions, roadmap control, or approval rights.

## Minimal GitHub Sponsors setup

GitHub Sponsors is part of the existing GitHub identity, so no additional public donation-service account is necessary. GitHub still requires payout onboarding before sponsorship money can be received. For a personal sponsored-developer account this includes the Sponsors profile/application, two-factor authentication, bank/payout information, and tax information. Bank payouts use GitHub's Stripe Connect onboarding.

If avoiding all external payout onboarding is an absolute requirement, there is no functional donation path: money cannot be transferred without a payout destination. In that case leave `FUNDING.yml` in place so the repository is ready, but do not claim sponsorship is live until the GitHub Sponsors profile has been approved.

## Suggested low-maintenance tiers

To minimize administrative work, use simple tiers with no promised support SLA or special development priority. For example:

- **$5/month — Supporter**: helps cover routine AI-token usage.
- **$15/month — Builder**: helps cover heavier development and test cycles.
- **$50/month — Sustainer**: helps cover recurring AI/GitHub/infrastructure costs.
- optional one-time tiers for people who prefer a single contribution.

Avoid rewards that create private-support obligations unless that is deliberately desired later.

## Repository policy

Funding never changes DevBridge's control-plane or project-governance security rules. Sponsors do not receive automatic task-author authority, workstation access, peer trust, decision authority, publication authority, or security-policy exceptions.
