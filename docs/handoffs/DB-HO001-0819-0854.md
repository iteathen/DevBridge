## Critical bug discovered at checkpoint

The current README/setup claims that a user can download only `devbridge.mjs` and run it. That is **false**.

Current `devbridge.mjs` contains:

```js
import { bootstrap } from './src/bootstrap/secure-bootstrap.mjs';
```

Therefore a fresh Windows install that downloads only `devbridge.mjs` fails with a module-not-found error for `secure-bootstrap.mjs`. The same design is not truly standalone on Linux either.

The next implementation must fix this before setup can be considered correct.
