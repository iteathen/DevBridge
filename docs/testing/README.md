# Testing guidance and audit evidence

This directory contains current verification guidance and historical audit records.

- [Verification governance](verification-governance.md): test selection, timing, evidence reuse, and invalidation under DB-019.
- [Developer instructions](../../AGENTS.md): required checks for a change.
- [Roadmap](../roadmap.md): current implementation and qualification work.

Dated audits describe only the revisions they examined. A past passing result does not establish current correctness, and an old missing-feature finding may have been resolved. Preserve historical records and put updated status in the current owners.
